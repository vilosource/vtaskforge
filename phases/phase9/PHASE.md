# Phase 9 — Project Hierarchy & Ad-Hoc Task Support

Adds the Project model as the top-level container, makes workplan and
milestone optional on tasks (enabling backlog/ad-hoc tasks), adds labels
for flexible grouping, and updates the web UI with a project dashboard
and backlog board.

Depends on Phase 8 (rename Phase → Milestone) being complete.

See docs/design/project-hierarchy-DESIGN.md for the full design.
